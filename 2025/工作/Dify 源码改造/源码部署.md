安装 Microsoft C++ Build Tools

根据错误信息中的提示，你需要安装 Microsoft Visual C++ 14.0 或更高版本。你可以从以下链接下载并安装 Microsoft C++ Build Tools：[Microsoft C++ Build Tools - Visual Studio](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

1. 访问上述链接。
2. 点击 “下载” 按钮，下载安装程序。
3. 运行下载的安装程序。
4. 在安装过程中，确保选择 “使用 C++ 的桌面开发” 工作负载。这将安装必要的编译器和工具。
5. 完成安装。
