创建 route：

```shell
curl -i "http://211.90.240.240:9180/apisix/admin/routes" \
  -H "X-API-KEY: edd1c9f034335f136f87ad84b625c8f1" \
  -X PUT \
  -d '{
    "id": "1",
    "uri": "/ip",
    "upstream": {
      "type": "roundrobin",
      "nodes": {
        "httpbin.org:80": 1
      }
    }
  }'
```

查看所有 route :

```shell
curl http://127.0.0.1:9180/apisix/admin/routes \
  -H "X-API-KEY: edd1c9f034335f136f87ad84b625c8f1"
```

查看所有 up-streams :

```shell
curl http://211.90.240.240:9180/apisix/admin/upstreams \
  -H "X-API-KEY: edd1c9f034335f136f87ad84b625c8f1"
```

监控指标：

```shell
curl -i http://127.0.0.1:9094/apisix/prometheus/metrics
```
