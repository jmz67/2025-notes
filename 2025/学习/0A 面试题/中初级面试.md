1. 题目01：请实现一个 Python 装饰器 retry，它可以在被装饰的函数抛出异常的时候自动重试 3 次，每次重试的间隔 2 秒。

考察点：异常处理，装饰器，时间控制

2. 题目02：假设你要设计一个基于 fastapi 或者是 flask 的大模型接口，要求：
- 接收用户输入的 prompt 并返回大模型的回答
- 支持流式的返回 Streaming Response 
- 限制每个用户一分钟最多调用十次

考察点：FastAPI，流式输出，速率限制 Rate Limiting 

3. 题目03：假设你要调用多个大模型 API，例如 OpenAI 和 Claude 的，你希望并行的调用这两个接口，并返回最快的结果。请使用 python 的 asyncio 和 httpx 实现这个逻辑。

考察点：异步编程，并发 HTTP 请求

4. 题目04：在 Dify 的二次开发中，我们需要存储用户的聊天记录。假设我们使用 PostreSQL，请设计数据库表结构，并使用 SQLAlchemy 定义相应的模型，要求：
- 记录用户 ID、对话 ID、用户输入、模型回答、时间戳；
- 允许用户根据 `对话 ID` 查询完整的聊天记录。

考察点：数据库设计、SQLAlchemy 使用。

5. 题目05：在 Dify 开发中，我们希望缓存大模型的 API 响应，以减少重复请求。请使用 **Redis** 实现一个缓存装饰器 `@cache_response`，使得相同的 API 请求在 10 分钟内不会重复调用，而是直接返回缓存结果。
