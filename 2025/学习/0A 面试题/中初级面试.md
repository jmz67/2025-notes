1. 题目01：请实现一个 Python 装饰器 retry，它可以在被装饰的函数抛出异常的时候自动重试 3 次，每次重试的间隔 2 秒。
考察点：异常处理，装饰器，时间控制

2. 题目02：假设你要设计一个基于 fastapi 或者是 flask 的大模型接口，要求：
- 接收用户输入的 prompt 并返回大模型的回答
- 支持流式的返回 Streaming Response 
- 限制每个用户一分钟最多调用十次
考察点：FastAPI，流式输出，速率限制 Rate Limiting
