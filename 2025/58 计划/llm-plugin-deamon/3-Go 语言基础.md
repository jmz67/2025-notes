
# 3.1 Go 语言介绍
---

Go 语言在多核并发上拥有原生的设计优势，充分利用现代硬件性能又兼容开发效率，设计的目标是为了既发挥类似 python 等动态语言的开发效率，又可以在这样的基础上提供 c 等编译型语言的性能和安全。

Go 语言具备很强的语言表达能力，支持静态类型安全，能够快速编译大型项目；同时也允许开发人员访问底层系统，极力挖掘计算机 CPU 资源，还提供了强大的网络编程和并发编程支持。

Go 语言具备以下特性：

- 从底层支持协程并发，无需第三方库支持，对开发者的编程技巧和开发经验要求低
- 支持自动垃圾回收，避免内存泄漏
- 支持函数多返回值
- 支持匿名函数和闭包
- 支持反射
- 提供强大的bi'a
